# v05 — Оптическая скамья: границы раздела сред и покрытия

[English](README.md) | **Русский**

Одиночные фотоны по одному падают на плоскую структуру между средой падения и средой выхода: одиночная граница,
четвертьволновой просветляющий слой, брэгговское зеркало, плёнка Фабри–Перо, тонкая металлическая плёнка или грань
призмы (полное внутреннее отражение; со второй призмой за зазором — нарушенное полное внутреннее отражение).
Руководство владельца: `../README.ru.md`; правила: `../RULES.md`.

Визуализация — обёртка над движком `lfphys` (`../../lfphys/LAYERS.md`): каждое физическое число берётся из движка;
в этой папке — оркестровка (установка, шкала времени фотонов, проверки) и рисование.

| модуль движка | слой | для чего |
|---|---|---|
| `core.optics.interfaces` | ядро | `stack`: r, t, R, T, A любой структуры (трансфер-матрицы); `field_profile`: \|E\|² s-света; `brewster`, `critical`: эталоны в замкнутой форме |
| `core.optics.thin_films` | ядро | замкнутые формулы для проверок (добавлен для v05, тесты в `lfphys/tests/test_thin_films.py`) |
| `core.constants` | ядро | скорость света c (времена полёта) |
| `theories.approx.ray_optics` | теории (приближение) | `snell`: направления лучей, только для рисунка |

## Причинная цепочка одного фотона (всё вычисляется в запуске)

1. **Излучение** в момент пуассоновского потока (интенсивность — живой параметр) с длиной волны и поляризацией
   источника в этот момент. Неполяризованный источник излучает s- или p-фотоны с вероятностью ½ каждый (см.
   приближения).
2. **Полёт до структуры** по плечу падения (0,30 м в среде падения, скорость c/n₀).
3. **У структуры**, с той структурой, что стоит в момент прихода: запуск вычисляет R, T, A для собственной длины
   волны фотона, его поляризации и текущего угла через `interfaces.stack` и разыгрывает его судьбу по правилу Борна
   (отражён с вероятностью R, прошёл с вероятностью T, поглощён с вероятностью A = 1 − R − T; A меньше 1e-14 —
   округление 1 − R − T в структуре без потерь — обнуляется, а R полагается равным 1 − T). Поглощённый фотон
   открывается здесь (он исчезает в структуре).
4. **Полёт до детектора**: 0,30 м в среде падения (детектор отражения) или в среде выхода (детектор прохождения).
   Судьба открывается только тогда, когда фотон достигает своего детектора (щелчок). До этого кадр показывает фотон
   как два пакета — на отражённом и на прошедшем плече — с весами R/(R+T) и T/(R+T), одинаковыми при любом исходе;
   когда момент прихода к одному из детекторов проходит без щелчка, его пакет исчезает (обновление Людерса по
   нулевому результату). Сам исход никогда не покидает запуск раньше щелчка.

Счётчики — накопление этих событий; ожидаемые доли — собственные R, T, A запуска для отрезка.

## Что запуск вычисляет на каждый отрезок (конфигурацию установки)

* r, t, R, T, A для s и p при текущих λ и θ (`stack`);
* R(θ), T(θ), A(θ) для s и p при текущей λ: 360 углов от 0 до 89,9° плюс точки около собственных критического угла и
  угла Брюстера запуска; R(λ), T(λ), A(λ) при текущем θ на сетке, равномерной по 1/λ, от 300 до 1600 нм, достаточно
  мелкой, чтобы на 2π набега фазы туда-обратно во всей структуре приходилось ~20 точек (300–1600 точек); кривые для
  поляризации источника (s, p или смесь 50/50);
* критический угол: деление пополам по собственному T(θ) запуска для голой границы n_in → n_out, которое становится
  точно 0, как только выходящая волна становится затухающей (Re(n_out cos θ_out) = 0); деление идёт до соседних
  углов binary64 и возвращает первый с T = 0, так что «θ ≥ θ_c» — это собственное T(θ) = 0 запуска. Слои этот угол не
  сдвигают (n sin θ одинаково во всех слоях), а T толстой структуры может обратиться в машинный нуль задолго до него
  (плёнка с показателем ниже n₀ становится затухающей за своим скользящим углом): деление по всей структуре
  показывало вместо него этот угол (найдено при исправлении по ревью 2026-10-23); для призмы с зазором — по голой
  грани;
* угол Брюстера одиночной границы: нуль собственного r_p(θ) запуска (метод Брента); для многослойной структуры
  показывается минимум собственного R_p запуска (по сетке, затем ограниченная минимизация Брента между соседними
  точками сетки), без замкнутой формы (для свободной плёнки это ровно arctan n с R_p = 0, что проверяют тесты);
* \|E(z)\|² s-света в структуре и на ±max(0,6λ, 0,2·толщина) вокруг неё (`field_profile`);
* направления лучей в каждом слое и в среде выхода для рисунка (`ray_optics.snell`, вещественная часть
  показателя).

## Установка меняется на ходу (владелец, 2026-10-23)

Каждый параметр — живой (параметров законов нет: этот мир — общепринятая физика). Изменение действует сразу и
начинает новый отрезок:

* источник (λ, поляризация, интенсивность): уже излучённые фотоны летят дальше со своими λ и поляризацией, встречают
  структуру, стоящую в момент их прихода, и считаются **переходными** (учитываются отдельно, не в новом отрезке);
* структура (тип, показатели, толщины, число пар, зазор): фотоны, ещё не дошедшие до структуры, встречают новую
  (переходные); прошедшие её летят дальше и учитываются в своём отрезке;
* среды или угол (n₀, n_s, θ: гониометр поворачивает источник и оба детектора): пути пучков перестраиваются, и
  фотоны в пути **теряются** (учитываются, с уведомлением).

Изменение отклоняется (и мир остаётся прежним), когда значение вне допустимых пределов. Изменение атомарно (ревью
2026-10-23, V5-1): новая установка, её отрезок и её проверки вычисляются с задержанными сообщениями, и сохраняется и
выдаётся только изменение, удавшееся целиком; если по пути что-то выбрасывает исключение, мир (параметры, структура,
летящие фотоны, счётчики, отрезки, генератор случайных чисел) восстанавливается, ничего из изменения не выдаётся, а
ошибка сообщается как отклонённое изменение, после чего исполнитель присылает действующие живые значения, и плеер
откатывает свой элемент управления. Углы, при которых волна скользит внутри слоя, и сам критический угол
принимаются (см. «Численные методы»).

Действия: «Выпустить один фотон» (один фотон сейчас, в дополнение к потоку), «Обнулить счётчики (новый отрезок)»
(новый отрезок с той же установкой).

## Проверки (вычислено ↔ эталон)

Каждая проверка выдаётся для каждого отрезка (`<id><отрезок>`).

| id | вычислено запуском | эталон | допуск |
|---|---|---|---|
| `sum` | R + T + A для поляризации источника | 1 — тождество (A определено как 1 − R − T), группа «Отрезок N: согласованность (тождества)» | 1e-12 |
| `energy` (без потерь) | max \|1 − R − T\| по всем вычисленным углам и длинам волн, s и p (R, T из r и t по отдельности) | 0 | 1e-10 (худшее на случайных структурах: 2e-13) |
| `passive` (поглощающая) | min A по всем вычисленным точкам | ≥ 0 | −1e-12 |
| `joule` (поглощающая) | R_s + T_s + A_J, A_J = k₀/Re(n₀ cos θ₀) Σ Im(n_j²)∫\|E\|²dz по полю запуска (теорема Пойнтинга) | 1 | 1e-12: составная 16-точечная формула Гаусса–Лежандра, подынтервалы ≤ 4/max(2\|Im k_z\|, 2\|Re k_z\|) (остаток < 1e-25); остальное — округление чисел с плавающей точкой, ≤ 1,5e-14 по 3000 случайным поглощающим плёнкам в пределах параметров (до 2026-10-23: Симпсон с 2001 точкой, +2,9e-8 при глубине скин-слоя 1,2 нм, V5-3) |
| `brew`, `brewR` (одна граница) | нуль r_p; R_p в нём | arctan(n_out/n₀); 0 | 1e-9; R_p < 1e-24 |
| `crit` | граница T = 0 для голой границы n_in → n_out | arcsin(n_s/n₀) | 1e-9 |
| `tir`, `tirnow` (без потерь) | max \|1 − R\| по 60 углам от θ_c до 89,9°; R при текущем θ > θ_c | 0; 1 | 1e-12 |
| `evan` (голая грань за θ_c) | длина затухания амплитуды по \|E\|² на грани и на глубине z (сначала z = λ/4, затем z = найденная так длина, чтобы ln(I(0)/I(z)) ≈ 2) | λ/(2π√q), q = n₀² sin²θ − n_s² в 160-битной арифметике (одно округление) | (4,5K + 9 + 15/ln)·2⁻⁵³, K = n₀² sin²θ/q (вывод ниже); там, где это больше 1e-2, показывается для сведения |
| `ar` | R(λ₀, 0°) четвертьволнового слоя | ((n₀n_s − n_f²)/(n₀n_s + n_f²))², 0 при n_f = √(n₀n_s) | 1e-12 абсолютно |
| `bragg` | R(λ₀, 0°) для (H L)^N | ((n₀n_L^{2N} − n_s n_H^{2N})/(n₀n_L^{2N} + n_s n_H^{2N}))² | 1e-10 |
| `film` (один слой) | r, t | формула Эйри (сумма многократных отражений) с комплексными коэффициентами Френеля, с косинусами Снелла и фазой слоя из движка | сумма оценок округления первого порядка обоих путей (`single_film` err_r/err_t ∝ 1/\|D\|, D = 1 + r₀₁r₁₂e^{2iβ}; `stack_error_single_layer`); где она больше 1e-9 (у скользящего угла в слое) или при точном скольжении (0/0), сравнение также при θ ∓ 1e-3 рад |
| `airy`, `airymax` (Фабри–Перо) | T при (λ, θ); максимум по спектру | T_max/(1 + F sin²(Δ/2)), F = 4ρ/(1−ρ)², ρ = √(R₁₀R₁₂), Δ = 4πn d cosθ/λ + arg r₁₀ + arg r₁₂ (= 1/(1 + F sin²(δ/2)) при n₀ = n_s), вычисленная с косинусами и фазой из движка | сумма оценок округления первого порядка обоих путей (airy err_T ∝ 1/(1 − ρ), F → ∞ чуть ниже скользящего угла в плёнке; матрицы err_T), в каждой точке; где она больше 1e-9, сравнение также при θ − 1e-3 рад (до 2026-10-23: собственные asin/cos угла в плёнке, 1e-10, провал до 0,1 чуть ниже скользящего угла) |
| `ftir` (призма + зазор за θ_c) | T | 1/(1 + ((a² + b²)/(2ab))² sinh²(κd)); s: a = k_z, b = κ; p: a = k_z/n₀², b = κ/n_s² | 1e-9 |
| `stat` | отсчёты всех трёх исходов (R, T, A) в отрезке | вероятности Борна отрезка: точный двусторонний биномиальный хвост каждого исхода с 0 < p < 1, поправка Бонферрони по исходам; исход с p = 0, который произошёл, имеет p-значение 0; z каждого и χ² Пирсона — в примечании | провал ниже p = 5,7e-7 (двусторонний хвост 5σ); до 2026-10-23 проверялось только R, поэтому перестановка T и A проходила (V5-4) |

**Замкнутая формула Брэгга зависит от порядка слоёв.** При порядке, принятом здесь (среда падения, H, L, …, H, L,
подложка), адмиттанс структуры Y = n_s (n_H/n_L)^{2N}, отсюда формула в таблице. Часто цитируемая формула
((n₀n_H^{2N} − n_s n_L^{2N})/(n₀n_H^{2N} + n_s n_L^{2N}))² относится к обратному порядку, когда к среде падения
прилегает L; обе сверены с трансфер-матрицами в `lfphys/tests/test_thin_films.py`.

## Сообщения

* `segment` (накопительное): установка (`setup`: структура, слои с комплексным показателем и толщиной, λ, θ,
  поляризация, времена полёта), `angles` (θ в каждом слое, θ на выходе или null), `cur` (R, T, A для s, p и
  источника), `expected` (вероятности Борна), `theta_B`, `min_rp`, `theta_c`, `theta_c_face`, `approx`; блобы: `th`,
  `Rs`, `Ts`, `As`, `Rp`, `Tp`, `Ap`, `Rc`, `Tc`, `Ac` (угловые кривые), `lam`, `lR*`, `lT*`, `lA*` (спектр), `z`,
  `E2` (поле).
* `clicks` (накопительное): точные отсчёты шага по отрезкам и исходам, `by_seg = [[seg, n_R, n_T, n_A], …]`
  (seg −1: переходные фотоны), и последние ≤256 отдельных регистраций шага (`t`, `det` 0/1/2 = R/T/A, `pol`, `seg`,
  `te`) для вспышек на виде.
* `frame` (может быть отброшено): отсчёты текущего отрезка, ожидание, биномиальная σ, z отражённой доли, итоги;
  блоб `fl` (n × 6): стадия, поляризация, продвижение к структуре или к детектору отражения, вес отражённого пакета,
  продвижение к детектору прохождения, вес прошедшего пакета.

## Приближения

* Плоские волны, бесконечные плоские границы; однородные изотропные линейные среды **без дисперсии**: каждый
  показатель преломления — одно число (комплексное при поглощении) для всех длин волн. Значения «как у материалов» в
  пресетах («как MgF₂», «как TiO₂/SiO₂», «как золото при 633 нм») иллюстративны, это не табличные данные о
  дисперсии.
* Одиночные фотоны по правилу Борна с вычисленными R, T, A (мощности плоских волн — вероятности трёх выходов).
  Неполяризованный источник — собственная смесь 50/50 s- и p-фотонов; изотропная плоская структура s и p не
  смешивает, поэтому вероятность каждого исхода равна вероятности для ρ = I/2.
* Полёт со скоростью c/n по плечам (без дисперсии фазовая и групповая скорости равны); время внутри структуры
  (микрометры) не учитывается; детекторы идеальны (эффективность 1, нет темновых отсчётов).
* Пучки на рисунке — геометрические лучи (закон Снелла, `ray_optics.snell`, с вещественной частью показателя в
  поглощающем слое); структура нарисована в масштабе по глубине, плечи по 0,30 м — нет. Яркость пучков — собственные
  R и T запуска.
* \|E\|² показывается только для s-поляризации (`field_profile` вычисляет только s); для p- или неполяризованного
  источника панель так и сообщает.

## Численные методы

* `interfaces.stack` перемножает характеристические матрицы слоёв (Абелеса), записанные без деления на наклонный
  адмиттанс (в форме sinc). Поэтому волна, скользящая внутри слоя без потерь (n₀ sin θ = n_j: зазор в установке с
  призмой при критическом угле грани, слой с малым показателем, видимый из более плотной среды падения), — регулярная
  точка, и угловые кривые берут эти углы точно. (Первая версия перемножала матрицы границ (1/t_j)[[1, r_j],
  [r_j, 1]], которые там делят на t_j = 0; запуску приходилось отклонять такие углы. Заменено в движке 2026-10-23.)
* Сетка спектра ограничена 1600 точками; очень толстая структура может тогда быть недоразрешена на коротких длинах
  волн, и запуск сообщает об этом в приближениях.
* **Проверки у критического и скользящего углов (ревью 2026-10-23, V5-2).** Там числа плохо обусловлены для любого
  вычисления в binary64, и фиксированный допуск проваливается на углах, которые можно набрать вручную
  (θ_c + 1e-7°, 41,8103149°). Поэтому допуски — оценки округления первого порядка, вычисленные для данного случая:
  * `evan`: cos θ_t = √(1 − x²) движка, x = n₀ sin θ/n_s, несёт 9u в x² (sin ≤ 1 ulp, ×n₀, /n_s, квадрат), то есть
    9uK в 1 − x² (вычитание у x = 1 точное), K = n₀² sin²θ/q; корень делит это пополам, а 2π, n_s, произведение и λ
    добавляют ≤ 5u: постоянная затухания с точностью (4,5K + 5)u. Каждое значение \|E\|² несёт ≤ (11 + ln)u, их
    отношение и логарифм — по 1u: ln с абсолютной точностью (15 + ln)u; деление и эталон (q в 160-битной
    арифметике, `thin_films.evanescent_q`) добавляют 3u. Допуск (4,5K + 9 + 15/ln)u, u = 2⁻⁵³. По 3100 случайным
    установкам при θ_c + 10^(−14…1)° (случайные n₀, n_s, λ) наибольшее |rel|/tol было 0,53. Там, где оценка больше
    1e-2 (в пределах ~1e-12° от θ_c), угол задаёт длину затухания лишь с точностью ~K u, и строка показывается для
    сведения (`info`); при θ = θ_c, как его даёт asin, постоянная затухания запуска ровно 0 (скользящая выходящая
    волна): до исправления это вызывало ZeroDivisionError внутри `set` (V5-1).
  * `film`: формула Эйри — отношение N/D, D = 1 + r₀₁r₁₂e^{2iβ} → 0, когда волна скользит внутри слоя, поэтому её
    округление растёт как 1/\|D\|; к тому же оба пути вычисляли косинусы Снелла по разным формулам с плавающей
    точкой, что сдвигает β = 2πn₁d cos θ₁/λ на ~(2πn₁d/λ)u/\|cos θ₁\| у скользящего угла (2,4e-12 для плёнки 20 мкм
    при n₀ = 4, 1,4e-7 у критического угла выхода). Теперь оба пути используют косинусы и фазу слоя из движка, а
    допуск — сумма двух оценок первого порядка (`thin_films.single_film` err_r, err_t: каждый коэффициент Френеля
    ≤ 6u, умноженные на число обусловленности его знаменателя, e^{2iβ} ≤ 2u, затем N и D, делённые на \|D\|;
    `thin_films.stack_error_single_layer`: элементы масштабированной характеристической матрицы ≤ 8u, B и C ≤ 12u
    от своих членов, затем знаменатель). По 120 000 случайным сравнениям наибольшее отношение было 0,25.
  * `airy`, `airymax`: то же построение для формулы интенсивности, записанной как
    T = T₀₁T₁₂/((1 − ρ)² + 4ρ sin²(Δ/2)) (сумма двух неотрицательных членов; sin²(Δ/2) точно равно sin²β или
    cos²β, так как коэффициенты Френеля вещественны).
