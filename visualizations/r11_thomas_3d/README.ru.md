# r11 — прецессия Томаса–Вигнера в 3D

[English](README.md) | **Русский**

Обёртка над движком `lfphys` (пункт плана P14.1, на основе P9 и P10) и второй мир 3D-среды плеера
(`../RULES.md` §2.10). Корабль стартует из покоя и выполняет манёвр; его гироскопы переносятся без вращения; когда он
снова в покое, они оказываются повёрнутыми. Запуск вычисляет, на сколько — в SO(3) и в SU(2), — сколько топлива на
это ушло, и сравнивает оба результата с формулами в замкнутом виде и с изопериметрической оценкой гиперболической
плоскости.

## Что вычисляет запуск (модули движка)

| модуль | слой | роль |
|---|---|---|
| `core.spin_transport` | ядро | манёвр: перенос Ферми–Уокера репера гироскопов вдоль разгонов (тяга постоянного направления в системе корабля) и поворотов (тяга, поворачивающаяся с постоянной скоростью вокруг оси, неподвижной в системе корабля), каждый участок — точно, через матричные экспоненты в группе Лоренца и, независимо, в SL(2, C); собственное и лабораторное время, положение, скорость, топливо; голономия; геометрия пространства скоростей (расстояния, углы, площади по Гауссу–Бонне, окружности, изопериметрическая оценка) |
| `core.lorentz` | ядро | бусты, разложение на буст и поворот, сложение скоростей, вращение Томаса–Вигнера (матрицы и формула в замкнутом виде), ось–угол в SO(3), ось–угол в SU(2) |
| `core.geometry` | ядро | плоскости срезов (`Plane.horizontal`, `plane_cut`) |

Установка (`engine/loops.py`, собственной физики нет): петли, построенные по параметрам мира, их эталоны, поле петель
из трёх разгонов.

## Физика

* **Пространство скоростей.** Скорости тела образуют гиперболическое пространство кривизны −1 в единицах быстроты;
  сцена рисует его как шар β = v/c (модель Бельтрами–Клейна: разгон постоянного направления идёт по прямой хорде;
  свет — граничная сфера |β| = 1). Топливо манёвра — длина его пути там: сумма быстрот разгонов, ∫|a| dτ / c.
* **Перенос Ферми–Уокера.** Репер гироскопов M(τ) (его базис в лабораторных координатах) подчиняется
  dM/dτ = M Ξ(τ), где Ξ — генератор буста собственного ускорения в собственной системе корабля. Разгон — это
  exp(η K·n); поворот (направление тяги a(s) = R(ω, κ s) a₀) — exp(s(K·a₀ + κ J·ω)) R(ω, −κ s), точно
  (`spin_transport._advance`). Те же участки в SL(2, C) переносят спинор.
* **Голономия.** Снова в покое оси гироскопов повёрнуты на R (прецессия Томаса). Для петли в одной плоскости
  пространства скоростей R — поворот вокруг нормали этой плоскости на охваченную площадь A, в направлении, противоположном обходу
  петли (Гаусс–Бонне; Aravind, Am. J. Phys. 65, 634 (1997)); равномерное движение по окружности при γ даёт
  2π(γ − 1) за оборот (Thomas, 1927). SU(2) хранит угол по модулю 4π: петля площади 2π оставляет гироскопы такими,
  какими они были, а спинор — со знаком −1.
* **Изопериметрическое неравенство.** Среди замкнутых кривых длины L на гиперболической плоскости наибольшую площадь
  охватывает окружность: L² ≥ 4πA + A², то есть A ≤ √(4π² + L²) − 2π (Osserman, Bull. AMS 84, 1182 (1978),
  формула (4.23), K = −1; равенство только для окружностей). Для плоских петель это ограничивает поворот на единицу
  топлива; для петель, выходящих из любой плоскости, она показывается только как линия сравнения — никакой оценки
  для них здесь не утверждается.

## Петли

| петля | что | эталон |
|---|---|---|
| `thomas` | разгон до быстроты ρ, равномерное движение по окружности (`turns` оборотов), обратно | Томас: 2π(γ − 1) за оборот, γ = cosh ρ |
| `circle` | окружность пространства скоростей радиуса ρ, проходящая через покой (тяга поворачивается со скоростью coth ρ на единицу быстроты от старта) | площадь круга 2π(cosh ρ − 1); равенство в изопериметрическом неравенстве |
| `triangle` | разгон ρ вдоль e₁, разгон ρ, повёрнутый на α, обратно в покой | угол Вигнера двух бустов = площадь треугольника (Люилье по его сторонам) |
| `polygon` | правильный n-угольник через покой с радиусом описанной окружности ρ (разгоны) | (n − 2)π − n α, cosh ρ = cot(π/n) cot(α/2) |
| `crown` | n-угольник, вершины которого поочерёдно подняты на ±χ из плоскости | нет: два представления согласуются; при χ = 0 — многоугольник |
| `helix` | тяга, поворачивающаяся вокруг оси, наклонённой на χ (винтовая линия в пространстве скоростей), затем обратно | нет; при χ = 0 — окружность |
| `seam` | шов теннисного мяча (широта χ sin 2t) на сфере пространства скоростей радиуса ρ через покой, 96 разгонами | нет; при χ = 0 — правильный 96-угольник; гладкий шов — предел (показана разность с 192 разгонами) |

Плоскость петли задаётся её нормалью (θ, φ); всё проверяется при любой ориентации.

## Сцена

* **Пространство скоростей**: световая сфера |β| = 1, покой, путь (открывается по мере хода лабораторного времени),
  тройки гироскопов вдоль него (красный, зелёный, синий: оси гироскопов 1–3 относительно репера, которого достиг бы
  один буст из покоя), корабль со своими гироскопами, его спин (жёлтый: ось, которая в начале направлена вдоль e₁) и
  тяга (оранжевая), ось поворота, когда петля замыкается; вершины многоугольников; **поле** (объём) и оси поворота
  этого поля (стрелки, при старте выключены). Каждый элемент выключается отдельно.
* **Поле**: для каждой скорости w шара — поворот гироскопов θ после петли покой → u → w → покой (u вдоль e₁ с
  быстротой η_u): угол Томаса–Вигнера бустов u и v′ (скорость w, видимая из u), вычисленный матрицами движка в каждой точке;
  или θ, делённый на изопериметрическую оценку при топливе этой петли (всегда меньше 1: треугольники плоские). Пусто
  там, где |β| > 0,999.
* **Срезы**: до трёх плоскостей любой ориентации через шар (общая среда: манипулятор, параметры, сохранение в новом
  мире, по желанию «автосмещение по нормали» — его скорость в c за год времени мира). Каждый срез вычисляется
  запуском в 160 × 160 точках своей плоскости и проверяется в трёх своих точках в сравнении с площадью треугольника по
  Гауссу–Бонне.
* **Обычное пространство**: траектория корабля (световые годы), тройки гироскопов вдоль неё, корабль, ось поворота в
  конце. Поля нет, поэтому нет и срезов. Область начинается с входного масштаба c²/a и удваивается всякий раз, когда
  открытый путь приближается к её краю (сообщение `box`), поэтому кадрирование никогда не выдаёт, куда полетит
  корабль.
* **Что и когда показывается** (RULES.md §2.2): в начале — только программа (участки, запланированное ими топливо,
  формула петли в замкнутом виде как описание); пока идёт время — путь, тройки, текущие t, τ, β, γ и наибольшее γ на данный
  момент; при замыкании — поворот (SO(3), SU(2)), накопленный угол, длительность в лабораторном и собственном времени,
  наибольшее γ, сравнение с оценкой и проверки.
* Время: часы мира считают лабораторные секунды (манёвр длится годы при 1 g; плеер показывает годы); скорость по
  умолчанию берётся из собственных часов программы (топливо / тяга, входные данные): около 20 с воспроизведения на год
  собственного времени на (c/a), дольше при большом γ.

## Приближения и ограничения

* Специальная теория относительности, плоское пространство-время; тяга задана в системе корабля и постоянна по
  величине (она задаёт лишь масштабы времени и длины); корабль — точка с идеальными гироскопами (без моментов сил).
* Разгоны многоугольников (треугольник, многоугольник, корона, шов) строятся с повышенной точностью (64-битная
  мантисса) и округляются до float64 по мере прохождения: при построении во float64 следующая вершина, видимая из
  сопутствующей системы, теряла до ε cosh²(η), и большие петли в наклонных плоскостях выгибались из своей плоскости
  сильнее, чем погрешность округления полёта (ревью B2-1). Поэтому сравнения ограничивает измеренная погрешность округления полёта.
* Манёвр, достигающий быстроты больше 7 (γ ≈ 550), отклоняется: float64 там потерял бы поворот (винтовая линия с почти
  осевой осью тяги уходит к свету). При быстроте 6 с шестью повторениями измеренная погрешность округления ~5e-7 (показано в
  `roundoff`).
* Шов — многоугольник из 96 разгонов (сам по себе полноценный манёвр); гладкий шов — его предел, разность показана.
* Изопериметрическая оценка — теорема для плоских петель; для остальных это линия сравнения.
* Часы мира считают секунды; скорость автосмещения плоскости — в c за год времени мира.

## Тесты

`tests/test_r11_thomas3d.py`: каждый пресет строится, замыкается и проходит свои проверки; ничего о результате не
появляется до замыкания, а путь открывается только до времени запуска; плоские петли (петля Томаса, окружность,
пятиугольник) в трёх ориентациях в сравнении со своими формулами в замкнутом виде в SO(3) и SU(2); края схемы (ρ = 3, шесть повторений,
24 стороны, χ = 80°) и наименьшее значение (ρ = 0,05): отказ с причиной или прохождение, измеренная погрешность округления далеко
ниже уровня тревоги, повторные петли через покой между повторениями; большие треугольники и многоугольники
(ρ 2 – 3, с повторениями) в наклонных плоскостях; лабораторная область растёт только вместе с открытым путём; ничего
из результата (ни длительности, ни собственного времени в конце, ни наибольшего γ) в заголовке; поворот на единицу
топлива повторённой неплоской петли — как у одной петли; треугольник — вращение Вигнера (матрицы и формула
в замкнутом виде); двойное накрытие (площадь 2π: гироскопы вернулись, спинор −1; дважды: спинор вернулся); корона, винтовая линия и
шов при χ = 0 — плоские петли, а вне плоскости их ось отходит от нормали; шов сходится; петля Томаса в обычном
пространстве — равномерное движение по окружности (скорость tanh ρ, радиус sinh²ρ c²/a) после гиперболического
движения; поле и три среза в сравнении с формулой Гаусса–Бонне, отношение меньше 1; плоскости сохраняются в новом мире, срезы при
автосмещении грубые, в обычном пространстве срезов нет; кадры несут ортонормированный репер гироскопов. Собственные
тесты движка: `../../lfphys/tests/test_lorentz_3d.py`, `test_spin_transport.py`. Страница: headless Chromium (WebGL
через SwiftShader), пресеты thomas, crown, spin_flip, lab и gauss из u38 после выделения общей среды
(2026-10-27, без ошибок страницы).
