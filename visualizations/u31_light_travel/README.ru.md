# u31 — Свет на больших расстояниях

[English](README.md) | **Русский**

Конечная скорость света от Солнца до Земли, световые конусы, гравитационное отклонение и задержка света, скорость
света, измеренная покоящимися наблюдателями и наблюдателями, движущимися по ходу света или навстречу ему,
синхронизация часов, относительность одновременности (парадокс Андромеды), эффект Доплера и гравитационное красное
смещение. Руководство владельца: `../README.ru.md`; правила: `../RULES.md`.

## Законы

| параметр | стандарт | модификации (с пометкой) |
|---|---|---|
| кинематика | СТО (преобразования Лоренца, c в любой инерциальной системе отсчёта) | `ether`: Галилей, свет летит со скоростью c относительно лабораторной системы (эфира); `emission`: Галилей, свет летит со скоростью c относительно своего источника (Ритц) |
| гравитация | ОТО (внешнее решение Шварцшильда для одного тела в начале координат) | `newton`: свет как ньютоновы корпускулы (Зольднер), только вместе с `emission`; `none`: тела поглощают свет, но не притягивают его |
| c | 299 792 458 м/с | `c_factor` ≠ 1 |

ОТО требует СТО, а ньютоновы корпускулы требуют баллистической теории (`Laws.validate`). Если изменён один закон, а
другой оставлен стандартным, мир берёт ближайший совместимый с ним закон и сообщает об этом (уведомление, текст
сценария; параметры в заголовке и список «Модифицированная физика:» — те, что действуют; ревью UX-params P12,
2026-11-05): эфир + ОТО → эфир без гравитации (тело только поглощает свет); баллистика + ОТО → баллистика + ньютоновы
корпускулы; ньютоновы корпускулы + СТО → баллистика. В сцене без тяготеющего тела (измерение c, Андромеда) закону
гравитации не на что действовать, и он ставится в «Без гравитации». Два изменённых закона, которые не сочетаются друг
с другом (эфир + ньютоновы корпускулы при наличии тела), отклоняются с указанием, что изменить. Линза радиуса 0
(чёрная дыра) — объект ОТО: без ОТО ей даётся радиус горизонта 2GM/c² её массы (выбор пресета
«Ньютоновы корпускулы у чёрной дыры (модификация)», `lensing_newton`), и об этом тоже сообщается. Пешеходы быстрее
света этого мира (Андромеда, СТО) отклоняются с числами, которые нужно изменить (P7).

## Сценарии (пресеты)

* **Солнце → Земля.** Вспышка на поверхности Солнца в t = 0; Земля на круговой орбите (закон Кеплера, точный для
  круговых орбит в координатах Шварцшильда), станция, покоящаяся там, где была Земля в t = 0, ракета на 0,5 а. е.
  Свету нужно (1 а. е. − R☉)/c ≈ 496,68 с плюс шапировская добавка ≈ 53 мкс. За время полёта Земля смещается
  примерно на 15 000 км.
* **Измерение c.** Три наблюдателя встречаются в начале координат в t = 0 со скоростями 0, +0,5c, −0,5c
  (параметры), несут стержни собственной длины L₀ вдоль x (или y) и синхронизуют свои часы B светом; источник на
  оси даёт вспышку. Варианты: часы, синхронизованные по лабораторной одновременности; эфир; баллистическая теория;
  поперечное плечо в эфире (Майкельсон–Морли).
* **Линзирование.** Чёрная дыра (или звезда заданного радиуса) между источником и наблюдателем; вспышка и
  параллельный пучок. Граница захвата пучка сравнивается с b_c = 3√3/2 rs, вычисленные пути — с точной квадратурой,
  отклонение на бесконечном пути — с формулой Дарвина в замкнутом виде. Наблюдатель получает два изображения вспышки в
  разные моменты.
* **Андромеда.** Три наблюдателя проходят мимо друг друга на Земле в t = 0 (пешком ±1,4 м/с или ±0,5c); событие на
  Андромеде в лабораторный момент 0. Их линии одновременности расходятся на v·D/c² ≈ ±4,26 сут на расстоянии
  2,5 млн св. лет; это показывает кнопка диаграммы «у Андромеды ±10 сут». Свет от события доходит до Земли через
  2,5 млн лет для всех.

## Действия (в запуске)

Вспышка от любого объекта; разгон наблюдателя (любая скорость и любое направление; его прибор разбирается, заново
собирается и заново синхронизуется в новой системе покоя); измерение туда-обратно прибором (плоские запуски) или
локальное измерение коротким радиальным стержнем (запуски в ОТО, статические наблюдатели); серия импульсов с
заданным собственным периодом (эффект Доплера, гравитационное красное смещение).

## Проверки, которые выдаёт запуск

| проверка | эталон (формула в замкнутом виде) |
|---|---|
| время полёта до приёмника (плоское пространство, СТО/эфир) | \|Δx\|/c |
| время полёта по радиусу (ОТО) | c t = r₂ − r₁ + rs ln((r₂ − rs)/(r₁ − rs)) |
| ход часов (ОТО) | статические √(1 − rs/r); на круговой геодезической √(1 − 3GM/(rc²)) |
| измеренная односторонняя скорость (пролетающая вспышка, собственный свет; вспышка между концами стержня приходит к A и B, идя в противоположные стороны: скорости нет, запуск так и говорит — ревью UX-params P9 [ошибка в прежнем]: показывалось c = 5,6·10⁸ … 7,8·10⁹ м/с) | СТО + синхронизация Эйнштейна: c; СТО + лабораторные часы: c/(1 + sβ); эфир: c(1 − β²) (Эйнштейн) или c − sv (лаборатория); баллистика: c + s(u − v) |
| скорость туда-обратно | СТО, баллистика: c; эфир: c(1 − β²) (вдоль), c√(1 − β²) (поперёк) |
| доплеровское отношение (коллинеарное) | СТО γ_r(1 − sβ_r)/(γ_s(1 − sβ_s)); эфир (1 − sβ_r)/(1 − sβ_s); баллистика 1 − s(β_r − β_s) |
| гравитационное красное смещение (статические концы) | √(f_e/f_r) как отношение частот |
| граница захвата пучка (открывается, когда ограничивающие её лучи дошли до горизонта или покинули сцену) | b_c = 3√3/2 rs (допуск = шаг лучей пучка) |
| угол поворота вычисленного луча | точная квадратура по тому же конечному пути |
| отклонение на бесконечности | форма Дарвина (1959) через эллиптические интегралы |
| одновременность у Андромеды | v·D/c² (СТО), 0 (абсолютное время) |
| локальная скорость света (ОТО, статический наблюдатель, стержень 10⁻³ r) | тот же конечный радиальный стержень в замкнутом виде (→ c при уменьшении стержня); рядом показана координатная скорость c(1 − rs/r) |
| время полёта в плоских запусках; ход часов статической станции | помечены «Самосогласованность»: это невязки решённых уравнений, а не независимые проверки; время полёта суммируется из решённого интервала (а не берётся разностью абсолютных моментов, которая при t ~ 4·10¹¹ с теряла 3·10⁻⁸ его величины: ревью UX-params P14 [ошибка в прежнем]), а допуск учитывает округление положения приёмника, взятого в абсолютный момент, 4ε(\|v\|\|t\| + \|x\|)/(cΔt) |

## Приближения и ограничения (названы, а не скрыты)

* Пространство — плоскость (x, y) плюс время; в ОТО одно сферическое тело в начале координат (точная внешняя метрика
  Шварцшильда). Остальные объекты собственной гравитации не имеют (пробные тела; собственное поле Земли не
  учитывается).
* В запусках ОТО карта пространства строится в координатах Шварцшильда; собственная система отсчёта наблюдателя
  (срезы одновременности движущегося наблюдателя) доступна только в плоских запусках; срезы в ОТО — статические
  (t = const).
* Прибор для измерения времени полёта есть только в плоских запусках; в ОТО скорость света измеряет локально
  статический наблюдатель коротким радиальным стержнем (туда-обратно по точным геодезическим).
* После разгона прибор собирается заново (мгновенная смена скорости протяжённого твёрдого стержня не определена).
  **Это явная идеализация:** новое зеркало B′ считается покоящимся на расстоянии L₀ в новой системе с момента
  разгона, как будто оно приготовлено заранее (это не причинный процесс); старое зеркало продолжает двигаться по
  инерции, уже посланный свет летит дальше, а начатые измерения завершаются по уже снятым показаниям (для пути
  туда-обратно, во время которого A сменил скорость, эталона в замкнутом виде нет). Пересинхронизация светом затем
  занимает реальное время.
* В ОТО разгон задаёт постоянную **координатную** скорость в координатах Шварцшильда (движение с тягой, а не
  свободное падение); локальная скорость для статического наблюдателя — (v_r/f, v_t/√f). Разгон, прямой путь
  которого пересёк бы тело или стал бы быстрее локального света, отклоняется с указанием причины.
* Тексты о приходе света в ОТО дают координатное время Шварцшильда; рядом приводится показание собственных часов
  приёмника.
* Баллистическая теория: движущееся зеркало переизлучает свет со скоростью c относительно себя (один из
  исторических вариантов).
* Земля сохраняет предписанную кеплерову орбиту и при выключенной гравитации света.
* В системе наблюдателя срез «сейчас» уходит в лабораторное будущее, которое запуск ещё не вычислил: эти части
  рисуются бледно и подписаны (действие ещё может их изменить); события, запланированные в начальных данных,
  показываются заранее полыми маркерами.
* Приёмники внутри фотонной сферы (r ≤ 1,5 rs) событий прихода не получают (запуск так и сообщает).
* Эфир покоится в лабораторной системе; ньютоновы корпускулы покидают статический источник со скоростью
  √(c² + 2GM/r₀) (вдали — скорость c).
* Рисуемые ломаные хранят вершину на каждые 0,25° поворота направления (или каждые 64 шага); моменты событий из
  них никогда не берутся.

## Тесты

`tests/test_u31_physics.py` (Docker: `docker compose -f visualizations/docker/docker-compose.yml run --rm viz-test`):
матрицы Лоренца сохраняют метрику; свет с аберрацией сохраняет скорость c; отклонение по квадратуре = Дарвин
(1e-10); слабое поле 2rs/b + 15π/16 (rs/b)²; время по радиусу; симметричная линза даёт два одновременных
изображения; каждая вершина RK лежит на точной геодезической (время до 1e-9); захват ниже b_c; пересечение по
Кеплеру = корпускула по RK; ньютоново отклонение вдвое меньше; каждый пресет запускается, и все его проверки
сходятся; в СТО измеренное c одинаково для всех наблюдателей; путь туда-обратно и пересинхронизация после разгона;
плечи Майкельсона–Морли в эфире; серии импульсов для эффекта Доплера и гравитационного красного смещения; сдвиги у
Андромеды ±4,264 сут; время полёта света Солнце–Земля и шапировская добавка; события открываются только тогда,
когда до них доходит время; один изменённый закон мир дополняет, два несовместимых отклоняет; пешеходы быстрее
света отклоняются; вспышка внутри стержня — не скорость (помеченные вспышки — ровно те, что между концами, по
положениям); времена полёта вдали от t = 0 сохраняют точность (отрицательный контроль: прежняя разность не
проходит).

## Источники эталонных формул

Darwin, C., Proc. R. Soc. A 249, 180 (1959), doi:10.1098/rspa.1959.0015 (точное отклонение в поле Шварцшильда);
IAU 2012 Resolution B2 (а. е., через scipy.constants); IAU 2015 Resolution B3, arXiv:1510.07674 (номинальные
R☉ = 6,957×10⁸ м, (GM)☉ = 1,3271244×10²⁰ м³ с⁻², R⊕ = 6,3781×10⁶ м, (GM)⊕ = 3,986004×10¹⁴ м³ с⁻²; значения
сверены с текстом grep 2026-10-22); стандартная специальная теория относительности для эффекта Доплера, аберрации
и одновременности; Зольднер (1801) для ньютонова отклонения 2GM/(c²b). Библиографические данные проверены по
Crossref 2026-10-22.
