# v12 — когда приходит частица? Времена прихода в 2D по применяемым правилам

[English](README.md) | **Русский**

Обёртка над движком `lfphys` (пункт плана P14.6, на основе P6 и v11). Волновой пакет летит вдоль z к регистрирующей
плоскости — свободно или через двойную щель v11. В квантовой механике нет самосопряжённого оператора времени, поэтому
правило Борна не задаёт распределение момента, в который частица достигает плоскости; в ходу несколько правил, и запуск
вычисляет каждое из них по одному и тому же опыту, чтобы было видно, где они согласуются (далеко от источника) и где
расходятся (вблизи источника, на цепочке пакетов, при обратном токе, за двумя щелями).

## Что считает запуск (модули движка)

| модуль | слой | роль |
|---|---|---|
| `core.quantum.schrodinger_nd` | core | волна на плоскости (метод расщепления оператора из v11), ток J(x, t) через плоскость, ψ и ∂ψ/∂z на ней (`plane_values`, порядок 32), вероятность, поглощённая в области (`absorbed_in`) |
| `core.quantum.schrodinger1d` | core | `FreeGaussians`: суперпозиции свободных гауссовых пакетов в замкнутом виде (ψ, ∂ψ, ток, импульсная амплитуда, P(z < L)): продольный множитель начального состояния, эталоны проверок |
| `core.quantum.transfer` | core | стационарное отражение мягкого детектора; поглощающие слои |
| `theories.interpretations.arrival_times` | интерпретация | внутренние правила: квантовый поток, первый приход по Бому (в 1D — скользящий максимум интеграла потока), Ааронов–Бом–Киёвский, полуклассическое |
| `theories.models.detection` | модель | модели детектора: правило поглощающей границы (Werner, Tumulka), экспоненциальные правила (Влодаж, Маркевка–Шусс), поглощающая ступень |

Аппаратная часть (`engine/apparatus.py`, без собственной физики): свободная геометрия и геометрия со щелями, удлинённые
для цепочки, начальные состояния, потенциал мягкого детектора, выбор поглощающего слоя экрана.

## Модель

* **Единицы** как в v11: длины в λ среднего импульса ħk₀, ħ = m = 1, k₀ = 2π, v₀ = 2π, E₀ = 2π²; единица времени —
  mλ²/ħ частицы; t₀ = D/v₀ — классическое время пролёта от центра ведущего пакета до плоскости.
* **Начальные состояния**, разделимые: χ(x)·φ(z), χ — гауссиан ширины σx, φ — суперпозиция гауссианов, ведущий пакет
  которой центрирован в источнике (z = 0 при свободном полёте; точка источника v11 — 4,5σz + w/2 + λ перед пластиной):
  `gauss` — один пакет с волновым числом k₀; `train` — N одинаковых пакетов на расстоянии sep друг от друга, каждый —
  сдвиг первого (несущая фаза e^{ik₀ j·sep}, Das & Struyve 2021, ур. 18; sep ≥ 6σz); `backflow` — медленный пакет (k₀/4,
  амплитуда 1,5) у источника и быстрый (k₀, амплитуда 1) на 3D позади него, подобранные так, что оба центра достигают
  плоскости одновременно: там они перекрываются, и ток некоторое время течёт назад (замкнутая формула: 1,53 %
  вероятности). Начальное состояние может иметь не больше 10⁻⁴ за плоскостью (иначе отказ).
* **Идеальная плоскость.** В основном запуске плоскость z = L — грань экрана: то, что её пересекает, поглощается
  безотражательным слоем в 4λ за ней (v11, со слоем, выбранным под спектр состояния: слой v11 6λ/2E₀ отражает 2,5 % при
  k₀/4, поэтому берётся самый узкий из (6λ, 2E₀), (12λ, E₀), (24λ, E₀/2), (36λ, E₀/2), (48λ, E₀/4) с отражением < 10⁻⁵
  и просачиванием < 10⁻⁶ в пределах ±3σ каждого пакета). Запуск записывает на каждом шаге J(t) = ∫ j_z(x, L, t) dx,
  J(x, t) по интервалам (≤ 360 × 240) для совместного распределения, ∫|ψ(x, L, t)|² dx и ∫|∂ψ/∂z(x, L, t)|² dx.
* **Правила** (плотности на единицу времени; Π dt — вероятность прихода в [t, t + dt]):
  * квантовый поток — Π = J(t); при обратном токе отрицателен (тогда это не плотность вероятности);
  * Бом — первое пересечение плоскости каждой траекторией ансамбля (интегрирование v11); при свободном полёте также
    точный закон первого прихода по потоку запуска: P(T ≤ t) = max_{s ≤ t} ∫₀ˢ J (формула трапеций от J(0) = 0: сумма
    прямоугольников забегала вперёд на dt/2, ревью B4-7) (одномерные траектории сохраняют порядок; движение разделимого
    состояния вдоль z одномерно);
  * Ааронов–Бом–Киёвский (АБК) — Π = (ħ/2πm) Σ_α |∫dk θ(αk) √|k| ψ̃(k) e^{ikD − iħk²t/2m}|² (Das & Nöth 2021, ур. 5), по
    импульсной амплитуде начального состояния (только свободный полёт); его вес при t < 0 (понимаемый как «не
    зарегистрировано») сообщается;
  * полуклассическое — Π = (mD/ħt²)|ψ̃(mD/ħt)|² (Das & Struyve 2021, ур. 3), пролёт отсчитывается от центра ведущего
    пакета; вычисляется через функцию распределения по k, P(T ≤ t) = ∫_{k ≥ mD/ħt}|ψ̃|² dk, рисуется средними по
    интервалам, а итоги считаются квадратурой по k (ревью B4-2: отсчёты плотности давали алиасинг гребёнки длинной
    цепочки и итоги 0,73–1,17);
  * поглощающая граница (Werner 1987; Tumulka 2022, ур. 3, 7) — ∂ψ/∂z = iκψ на плоскости, срабатывания
    (ħκ/m)|ψ(L, t)|², ψ(L, t) — методом изображений (свободный полёт, k > 0); κ в единицах k₀ (волна с k = κ поглощается
    полностью, остальные отражаются с коэффициентом (k − κ)²/(k + κ)²);
  * экспоненциальные (Das & Struyve 2021, ур. 5 и табл. I) — Π = λ e^{−∫λ} с λ_W = λ₀ v₀ ∫|ψ(x, L, t)|² dx (Влодаж)
    или λ_MS = λ₀ (v₀/k₀²) ∫|∂ψ/∂z(x, L, t)|² dx (Маркевка–Шусс: (λ₀′ε/π)|∂ψ̄|² из табл. I, где ψ̄ — решение со
    стенкой Дирихле в L, ∂ψ̄ = 2∂ψ, ε = ħ/m, так что здесь λ₀′ = πλ₀v₀/(4k₀²) = λ₀/8), так что λ₀ — среднее число
    срабатываний, которое вызвал бы пакет, если бы не исчезал; на плоскости — пуассоновский процесс с плотностью
    интенсивности λ(x, t) (обобщение одномерных правил в этом мире); первое срабатывание на шаге длины dt имеет
    вероятность e^{−Λᵢ₋₁} − e^{−Λᵢ}; то, что не срабатывает никогда, сообщается;
  * мягкий детектор (Allcock 1969; Muga, Palao & Leavens 1999) — второй запуск того же опыта, экран которого —
    поглощающий потенциал −iW₀, нарастающий на ширине края у плоскости (и слой v11 за ним): его срабатывания —
    поглощённая им вероятность; остальное отражается.
* **Через щели** полёт не свободный: правила АБК, полуклассическое и поглощающей границы там не определены и не
  рисуются; правила потока, Бома, экспоненциальные и мягкого детектора — рисуются. Закрытие щели в полёте действует на
  оба запуска сразу (Das, Deckert, Kellers, Krekels, Struyve 2024: динамическая двойная щель).

## Что и когда показывается

Сцена v11, в 3D после поправки владельца от 2026-10-28: ничто не зависит от y, поэтому волна — точное произведение
ψ(x, z, t)·η(y, t) со свободным гауссианом η ширины σy (параметр мира), нарисованное как объём; частицы Бома и их
траектории в x, y, z (y₀·σy(t)/σy); регистрирующая плоскость показывает P(x, y) (README v11, «Плоскость и третье
измерение»); пластина, если есть; окно плоскости y = 0. Время прихода от y не зависит (поток произведения через
плоскость равен J(x, t)|η(y, t)|²), поэтому правила ниже — правила плоскости. Панели этого мира: «Распределение времени
прихода» — Π(t)·t₀ в зависимости от t/t₀ для каждого правила (ансамбль Бома — гистограммой, нормированной на весь
ансамбль), каждое до показанного момента (правила, вычисленные из начального состояния, тоже: их кривые приходят с
сообщениями запуска, когда его время до них доходит); ось времени начинается с 2 t₀ (масштаб установки) и растёт со
временем запуска — длина окна является следствием запуска и появляется только в итогах (ревью B4-5); «Место и время
прихода» — совместное распределение J(x, t) (тёплые цвета — в плоскость, синий — назад; интервалы t₀/120, интервал
рисуется, когда целиком лежит в прошлом) с попаданиями частиц Бома (x, t) поверх; «Итоги по правилам» в конце окна —
вероятность каждого правила в пределах окна и его среднее время, то, что экспоненциальные правила никогда не
регистрируют, отражение мягкого детектора, вес АБК при t < 0, обратный ток. Окно наблюдения заканчивается, когда при
свободном полёте плоскость пересекло всё, кроме 10⁻⁴ (замкнутая формула, ×1,02), или когда за щелями волна покинула
окно (правило v11).

## Приближения и пределы

* Из v11: нерелятивистский расчёт, два измерения (ничто не зависит от y), поглощающие слои как детекторы идеальной
  плоскости, геометрия в длинах волн.
* АБК, полуклассическое правило и поглощающая граница вычисляются для свободного полёта из начального состояния и
  разделимого состояния (поперечный пакет — наблюдатель со стороны): маргинальное по времени распределение каждого
  правила для плоскости совпадает с его одномерной формой для φ(z).
* Экспоненциальные правила на плоскости — обобщение одномерных правил в этом мире (пуассоновский процесс с плотностью
  интенсивности λ(x, t)); их λ₀ — свободный параметр детектора, как в статьях.
* Край мягкого детектора — параметр мира (≥ шага сетки): резкая ступень сходится на сетке лишь как h² (ошибка 45 % при
  λ/6 в одном измерении), разрешённый край отражает гораздо меньше резкой ступени (стационарное значение для резкой
  ступени дано для сравнения в пояснении к проверке).
* Стоимость: сценарии занимают 10–138 с на GPU 0 (основной запуск, компаньон, запуск мягкого детектора, 2000 частиц
  Бома); опыт с оценкой больше 10 мин на GPU 0 или часа на CPU отклоняется (правило v11).
* Закрытие щели, пока волна внутри неё, — внезапное переключение стенки: оно порождает волны, которые сетка может не
  разрешить, и `numerics` об этом сообщает (плавное закрытие, как у Das et al., не реализовано).
* Открытые вопросы: `../../STATUS.md` (V30).

## Тесты

`tests/test_v12_arrival_times_2d.py` (малые геометрии): каждый сценарий строится и проходит свои статические проверки;
малый свободный пакет проходит все проверки, идеальные правила вдали от источника согласуются в среднем времени,
совместное распределение записывается; ничто не приходит раньше, чем может волна; поток состояния с обратным током
становится отрицательным, а плотность первого прихода по Бому — нет, и поток при этом следует замкнутой формуле;
экспоненциальное правило на цепочке подавляет поздние пики; через щели щель, закрытая в полёте, действует на оба запуска,

мягкого детектора и для ψ, ∂ψ на плоскости. Детекторы на ходу (ревью UX-ui U12): λ₀ и W₀, заданные при t = 0, дают мир,
