# v07 — Тест Белла на запутанных парах

[English](README.md) | **Русский**

Пары фотонов, запутанных по поляризации, |Φ+⟩ = (|HH⟩ + |VV⟩)/√2, или синглеты спина ½ (|↑↓⟩ − |↓↑⟩)/√2 летят от
источника к двум станциям; каждая станция измеряет свою частицу при одной из двух настроек; запуск считает совпадения
и оценивает корреляции E и параметр CHSH S. Руководство владельца: `../README.ru.md`; правила: `../RULES.md`.

Визуализация — **обёртка над движком `lfphys`** (`../../lfphys/LAYERS.md`): каждый закон берётся из модуля движка;
собственный код папки — шкала времени, логика установки (станции, выбор, учёт), сообщения и рисование.

| модуль движка | слой | для чего |

| `theories.alternatives.local_hidden` | теории (альтернатива) | миры ЛСП (локальных скрытых параметров): `polarization_model` (фотоны), `sign_model` (спин), со своими точными `*_E`; в квантовых мирах — только кривая для сравнения на графике E(Δ) (в списке модулей мира не значится) |
| `core.causality` (новый, 2026-10-23) | ядро | интервал s², причинное отношение, скорость, при которой порядок событий каждой пары меняется на обратный |

## Причинная цепочка одной пары (всё вычисляется в запуске)

Геометрия: прямая, источник в x = 0, станция Алисы в x = −L, станция Боба в x = +L (лабораторная система). Фотоны
летят со скоростью c; частицы со спином ½ — со скоростью v = β c (параметр мира, иллюстративный). Обе частицы пары
приходят в момент t_e + L/v.

1. **Излучение** в момент пуассоновского потока (интенсивность меняется на ходу).
2. **Выбор настройки** (режим «случайный»: «Выбор настройки» =
   «случайный для каждой частицы (как в опытах без лазеек)»): генератор случайных чисел станции выдаёт честный бит
   (0 → a или b, 1 → a′ или b′) в момент t_c = t_arr − τ, то есть за τ до прихода частицы (τ — задержка генератора и
   переключателя). Бит ни от чего в запуске не зависит; он разыгрывается, когда запуск доходит до t_c (или, если τ
   больше времени полёта, при излучении пары: тогда t_c лежит раньше излучения, как у генератора, выход которого
   задержан на τ). Режим «фиксированный» («фиксированный: Алиса a, Боб b»): Алиса использует a, Боб — b;
   «событие выбора» станции — момент, когда её настройка была задана в последний раз.
3. **Регистрация** в момент t_arr: действует угол анализатора, установленный в этот момент (изменение угла на ходу
   применяется к каждой частице, пришедшей после него), а исходы обеих частиц определяются законом мира:
   * квантовый: `qubits.sample_pairs(state, Π(α_A), Π(α_B))` — совместные вероятности Борна Tr(ρ Π_i ⊗ Π_j); индекс 0
     (прошла поляризатор / спин вверх по направлению магнита) — исход +1. При идеально (анти)коррелированных
     настройках одна из них точно 0, а след с плавающей точкой даёт ±1e-17; движок обнуляет отрицательное значение в
     пределах округления следа (4·dim·eps) (`qubits.born_probabilities`, ревью 2026-10-23 V7-1: прежде примерно
     половина таких настроек, например a = b = 30°, останавливала запуск);
   * локальные скрытые параметры: `local_hidden.polarization_model(α_A, α_B)` (фотоны: общая поляризация λ, закон
     Малюса независимо на каждой стороне, E = ½ cos 2(α_A − α_B)) или `local_hidden.sign_model(θ_A, θ_B)` (спин:
     общий единичный вектор λ, A = sign(a·λ), B = −sign(b·λ), E = −1 + 2θ/π). Функция движка разыгрывает λ и оба
     исхода одним вызовом; её код вычисляет A только по (α_A, λ), а B — только по (α_B, λ) (локальность по
     построению), и запуск вызывает её в общий момент прихода, когда обе настройки известны; по распределению это
     равносильно розыгрышу λ при излучении.

   Исходы открываются (сообщение `pairs`, вспышка на виде) только в момент t_arr. До своего момента запуск ничего не
   вычисляет о паре, кроме учёта излучения. Чтобы запись оставалась небольшой, сообщение `pairs` несёт подробности по
   каждой паре (моменты, настройки, исходы, события выбора, пространственно-временные признаки) не более чем для 16
   новейших пар каждого шага и число пар; каждая пара входит в счёт, который несут кадры.
4. **Пространственно-временные отношения событий пары** (`core.causality.relation`, лабораторная система): выбор
   Алисы (t_cA, −L) и регистрация у Боба (t_arr, +L), выбор Боба и регистрация у Алисы (локальность:
   пространственноподобность означает, что никакой сигнал от выбора не может достичь другой регистрации); каждый
   выбор и испускание пары (t_e, 0) (свобода выбора). Для фотонов в симметричной геометрии оба условия имеют вид
   0 < cτ < 2L. Для частиц медленнее света условие локальности остаётся cτ < 2L, а условие свободы выбора
   принимает вид |L/v − τ| c < L; оба могут выполняться, только если v > c/3 (вычисляется для каждой пары;
   показывается долями).

Счёт совпадений ведётся по каждой фактически использованной паре углов анализаторов (не более 200 пар; самая старая
неиспользуемая отбрасывается). Четыре ячейки CHSH — текущие (a, b), (a, b′), (a′, b), (a′, b′); после изменения угла
ячейки относятся к новым углам, а старые пары углов остаются на графике E(Δ). Действие «Сбросить статистику»
начинает счёт заново.

## Установка на ходу, параметры мира, действия (RULES.md §2.4)

* На ходу (действуют сразу): четыре угла, режим (фиксированный / случайный), τ, L, интенсивность пар.
  * угол: частицы, пришедшие после изменения, измеряются при новом угле; в режиме «фиксированный» событием выбора
    станции становится момент изменения;
  * режим: переключение на «случайный» назначает выборы летящих пар на max(t_arr − τ, сейчас) — никогда не раньше
    переключения; переключение на «фиксированный» делает текущий момент событием выбора обеих станций;
  * τ: ожидающие выборы переназначаются на max(t_arr − τ, сейчас);
  * L (станции сдвигаются): частица, уже пролетевшая новое положение станции, теряется (учитывается, уведомление);
    остальные приходят, когда достигают его (t_e + L_new/v);
  * интенсивность: следующее излучение разыгрывается заново (пуассоновский поток не имеет памяти).
* Параметры мира (новый мир): тип пар, скорость частиц со спином ½, закон. У закона `standard = "quantum"`; «lhv»
  помечается «МОДИФИЦИРОВАННАЯ ФИЗИКА».
* Действие: «Сбросить статистику».

## Проверки (панель «Проверки: вычислено ↔ эталон»)

* Состояние источника (квантовые миры): согласованность (concurrence) = 1 и одночастичная энтропия = 1 бит (движок) —
  тождества.
* Настройки, точно (выдаются заново после каждого изменения угла): S закона при текущих углах — квантовый: след
  движка в сравнении с формулами в замкнутом виде cos 2(α_A − α_B) (фотоны) и −cos(θ_A − θ_B) (спин), допуск 1e-12; |S| ≤ 2√2
  (квантовый); для ЛСП |S| ≤ 2; точная невозможность передачи сигнала в законе (квантовый: маргинальные вероятности из
  совместных вероятностей Борна, наибольшая разность < 1e-14). В мирах ЛСП две строки — тождества модели и
  показываются **для сведения** (≈, `info: true`, никогда ✓/✗): невозможность передачи сигнала в законе (P(+) = 1/2 при любой
  настройке другой стороны по построению: исход каждой стороны зависит только от её собственной настройки и λ) и
  |S| ≤ 2√2 (следует из |S| ≤ 2); проверка невозможности передачи сигнала в мире ЛСП — та, что ниже, по счёту запуска.
* Статистика пар запуска (выдаётся заново, когда счёт вырастает на 30 %, не реже чем каждые 100 пар; ячейка
  сравнивается, когда в ней ≥ 30 пар): E каждой ячейки в сравнении с точным E закона (z-оценка с погрешностью под эталоном,
  допуск 5σ); S в сравнении с S закона (5σ). Погрешность S: четыре различные ячейки — независимые выборки,
  Var S = Σ Var E_k; при совпадающих настройках (a′ = a или b′ = b) две ячейки — одна и та же пара углов, то есть
  один и тот же счёт, поэтому погрешность их объединяет: S = Σ_c w_c E_c по различным ячейкам, w_c — сумма знаков
  CHSH ячеек, равных c, Var S = Σ_c w_c² Var E_c (`bell_stats.chsh(…, keys)`; например, a′ = a: S = 2E(a,b),
  Var S = 4 Var E(a,b)); строка S тогда сообщает, что настройки совпадают и что S — не проверка CHSH (ревью
  2026-10-23 V7-2: прежде погрешность предполагала четыре независимые ячейки и была в 1,55–1,65 раза меньше при
  a = a′ = 0, b = 45°, b′ = 0, и 0,032 вместо 0 при b′ = 45°, b = 0). Разность для проверки невозможности передачи сигнала между двумя
  совпадающими ячейками тождественно равна 0 и показывается для сведения. Квантовые миры: (|S| − 2)/σ, ✓, как только
  она превысит 5 (пока нет — с числом ещё нужных пар); миры ЛСП: |S| ≤ 2 + 5σ; |S| ≤ 2√2 + 5σ; χ² всех измеренных
  точек E(Δ) относительно закона (p > 1e-6); невозможность передачи сигнала по счёту: P_A(+|x, b) − P_A(+|x, b′) и
  P_B(+|a, y) − P_B(+|a′, y) в сравнении с 0 с объединённой биномиальной погрешностью (5σ).
* Пространство-время (выдаётся заново после изменений L, τ, режима): для пары, излучённой сейчас, s² выбора Алисы и
  регистрации у Боба (движок) в сравнении с формулой в замкнутом виде c²τ² − (2L)²; их отношение — в подписи; для
  пространственноподобных событий скорость смены порядка v*/c = cτ/(2L) (движок) в сравнении с поиском корня на матрицах
  Лоренца из `core.relativity`, применённых к разности событий (преобразование самих событий по отдельности
  вычитало близкие члены ~L и теряло ~εL/(cτ) корня: 1,2·10⁻⁸ при τ = 1 пс, L = 10⁵ м — проваленная проверка в
  верном мире, ревью UX-params P21); s² выбора и испускания в сравнении с c²(L/v − τ)² − L². Доли зарегистрированных пар, у
  которых оба выбора отделены от другой регистрации и от испускания пространственноподобным интервалом (без эталона).

Допуск 5σ делает ложный провал одной проверки примерно 6·10⁻⁷ на одно вычисление; каждая проверка вычисляется заново
по мере роста счёта, поэтому за долгий запуск несколько десятков вычислений на проверку остаются далеки от ложной
тревоги.

## Приближения и ограничения (названы)

* Идеальные источник и детекторы: каждая излучённая пара регистрируется на обеих станциях (нет потерь, темновых
  отсчётов, многопарного излучения, видность единичная). Реальные опыты должны закрыть **лазейку регистрации**
  (достаточно высокая эффективность или неравенства CH/Эберхарда) и **лазейку локальности** (пространственноподобная
  разделённость каждого выбора настройки и измерения на другой стороне, с учётом длительности измерения); опыты без
  лазеек: Hensen et al. 2015, Giustina et al. 2015, Shalm et al. 2015. Здесь измерение — мгновение в момент
  прихода.
* Одна прямая, симметричный источник посередине, обе частицы с одинаковой скоростью: две регистрации пары
  одновременны в лабораторной системе.
* Выбор настройки — честная монета из генератора запуска с заданной затравкой (псевдослучайный); показываемая
  «свобода выбора» — только пространственно-временное отношение.
* Две модели ЛСП — иллюстративные представители класса, ограниченного CHSH (|S| ≤ 2): поляризационная модель даёт
  не более |S| = √2, знаковая модель достигает 2 при оптимальных для спина углах. Любая локальная модель
  подчиняется |S| ≤ 2; визуализация не ищет в классе лучшую.
* Статистические погрешности используют нормальное приближение (≥ 30 пар на ячейку).
* Пресеты иллюстративны (расстояния и τ не взяты из конкретного опыта).

## Тесты

`tests/test_v07_bell.py` (обвязка `../tests/harness.py`): каждый пресет запускается без ошибок и без проваленной
проверки; квантовые миры дают |S| в пределах 5σ от 2√2 и выше 2 более чем на 15σ (40 000 пар); миры ЛСП никогда не
превышают 2 + 5σ (по три затравки) и воспроизводят S своей модели; невозможность передачи сигнала по счёту; розыгрыш обёртки
в сравнении с учебными формулами в замкнутом виде при случайных углах для всех четырёх сочетаний закон × пары; исходы открываются только
при приходе (t_arr = t_e + L/c); случайный выбор пространственноподобен, медленный выбор (cτ > 2L) времениподобен;
пространственно-временные проверки в сравнении с формулами в замкнутом виде для четырёх геометрий; изменение угла на ходу применяется к
следующим приходам и сохраняет обе пары углов на графике E(Δ); отклонённое изменение оставляет мир без изменений;
сдвиг станций теряет ровно обогнанные пары; переключения режима назначают выборы не раньше переключения; действие
сброса; новый мир с другим законом в том же запуске; содержимое кадра и заголовка, которое рисует вид; идеально
(анти)коррелированные фиксированные настройки (фотоны a = b = 30°, a − b = −90°; спины a = b = 30°, a = 50°,
b = 230°) идут без ошибок с E = ±1 точно (V7-1); погрешность S при совпадающих настройках совпадает с разбросом по 40
затравкам, и настройки помечены (V7-2); в мирах ЛСП строки невозможности передачи сигнала в законе и границы Цирельсона — для
сведения, а не проверки (V7-3). Тесты новых модулей движка: `lfphys/tests/test_causality.py` (сверка с
`core.relativity.boost_matrix`), `lfphys/tests/test_bell_stats.py` (сверка с повторениями Монте-Карло, включая
совпадающие ячейки), `lfphys/tests/test_born_round_off.py` (нулевые ячейки совместных вероятностей Борна).
