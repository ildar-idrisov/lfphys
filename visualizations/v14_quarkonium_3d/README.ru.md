# v14 — кварконий в 3D: волновые функции пары тяжёлых кварков (корнеллская модель)

[English](README.md) | **Русский**

Обёртка над движком `lfphys` (пункт плана P14.9). Пара очарованный кварк–антикварк (cc̄) или прелестный
кварк–антикварк (bb̄), связанная корнеллским потенциалом V(r) = −κ/r + r/a², в трёхмерной среде плеера: облако |ψ|²
вектора между кварками, ток вероятности, плоскости среза с |ψ|² и фазой ψ, диаграмма уровней модели в сравнении с измеренными
массами, усреднёнными по спину. Состояния 1S, 2S, 3S, 1P, 2P, 3P, 1D, 2D, 3D (вещественные или комплексные угловые части)
и суперпозиции двух. **Физика — подогнанная модель**: мир так и помечен (`approximations` в заголовке, панель движка
показывает `theories.models.cornell` вне ядра).

## Что считает запуск (модули движка)

| модуль | слой | роль |
|---|---|---|
| `theories.models.cornell` | модель | потенциал и его подогнанные параметры κ = 0,52, a = 2,34 ГэВ⁻¹, m_c = 1,84 ГэВ, m_b = 5,18 ГэВ (Eichten & Quigg 1995 со ссылкой на Eichten et al. 1980); коробка, нужная состоянию |
| `core.quantum.radial` | core | радиальные функции: синус-DVR на N и 2N + 1 точках; энергии экстраполируются (Ричардсон); u(r) экстраполируется при L = 0 (член 1/r), при L ≥ 1 берётся с мелкой сетки (`wavefunctions`, точность измерена на водороде) |
| `core.quantum.central3d` | core | радиальная таблица (сплайн R/r^L, значение в начале координат — кубикой по методу наименьших квадратов), ψ = R·Y_lm, суперпозиции, ток, квадратуры, ⟨T⟩ + ⟨V⟩, матричные элементы |
| `core.data` | core | измеренные массы (PDG 2024), усреднённые по спину в каждом мультиплете |
| `core.geometry` | core | плоскости среза |

Аппаратная часть (`engine/pair.py`): решения для каждого L с их коробкой, таблицы, независимый путь проверок.
Серверная часть и вид — общие с v13 (`../server/lfviz/orbitals3d.py`, `../player/js/orbitview.js`).

## Модель

* **Единицы.** ГэВ и ГэВ⁻¹ (ħ = c = 1), приведённая масса μ = m_q/2; сцена — в фемтометрах (ħc = 0,19733 ГэВ·фм),
  энергии — в МэВ, часы мира — в секундах (ħ/ГэВ = 6,58·10⁻²⁵ с).
* **Что предсказывает модель.** Расщепления M(n, L) − M(1S) (в пределах 2–10 % от измеренных, усреднённых по спину), а
  не абсолютные массы (с этими параметрами 2m_c + E(1S) на 870 МэВ выше измеренного 1S; STATUS V17). Панель «Состояние»
  даёт M − M(1S) и энергию E в потенциале; диаграмма уровней рисует расщепления модели (сплошные) и данных (штриховые,
  где PDG приводит мультиплет: 1S, 1P, 2S для чармония; 1S, 1P, 2S, 3S для боттомония). Нет спин-зависимых сил, нет
  релятивистских поправок, нет связи с каналами открытого аромата: состояния выше порога D D̄ / B B̄ (cc̄ 2P, 3S, 1D…) —
  состояния модели, а не природы.
* **Радиальные функции** численные: нарисованные — с N = 800, для проверок — из второго решения при N = 1200. Их
  точность — проверка каждого мира («Сходимость: R(r) сетки N = 800 в сравнении с N = 1200»: они отличаются меньше чем на
  половину шага квантования 8-битной картинки; измерено ниже). Облако, ток, время, фазы суперпозиции и срезы — как в v13 (см. его
  README, раздел «Модель»).
* **Облако** — распределение r = r_q − r_q̄; собственное распределение каждого кварка относительно центра масс — то же
  облако, уменьшенное вдвое.

## Параметры на ходу и параметры мира (ревью UX-ui U12)

Как в v13 (его README, раздел «Параметры на ходу и параметры мира»): состояние — одно или суперпозиция, n, L, m, вид
угловой части, второе состояние, |c₂|² и фаза c₂ — меняется **на ходу**: идеальное приготовление нового состояния в
текущий момент t_p (прежнее отбрасывается, динамика перехода не моделируется) в том же мире с его часами, записью и
плоскостями срезов; коробка, облако, ток, срезы и проверки состояния (сходимость, энергия, узлы, расщепления модели
в сравнении с данными как информация) строятся для него в t_p, период суперпозиции отсчитывается от t_p, проверки прежнего
состояния, которых новое не даёт, выводятся из обращения как информация. Сетка облака меняется **на ходу** (то же
состояние в тот же t_p, пересчитанное). Пара кварков (cc̄ / bb̄) остаётся параметром мира: это и есть система (масса
кварка, уровни модели); другая пара — новый мир в том же запуске. Заголовок называет пару, а не состояние.

«+ плоскость»: первое размещение наклонной плоскости. В суперпозиции каждое новое размещение заново передаёт 24 фазы

перестаёт расти со временем после одного периода, но не при исследовании плоскостей. После ревью B4-10 шкала яркости
облака — (Σ_k |c_k||ψ_k|)² по сетке (граница, известная без эволюции), поэтому облако суперпозиции никогда в точности не
достигает полной шкалы; числа выше измерены с прежней шкалой (наибольшая плотность за период).

## Приближения и пределы

* Подогнанная нерелятивистская модель, усреднённая по спину (см. выше); κ и a — не параметры КХД (бегущая константа
  связи находится в `core.qcd`).
* Численные радиальные функции (измерено выше); 8-битная амплитуда облака и 10⁻³ вне нарисованного шара — как в v13.
* Открытые вопросы: `../../STATUS.md` (раздел V; V17 — об абсолютной шкале модели).

## Тесты

`tests/test_v14_quarkonium3d.py`: каждый сценарий строится и проходит свои проверки (суперпозиция — через один период),
помечен как модель и показывает расщепления модель–данные как информацию; уровни мира совпадают с `cornell.splittings`
в пределах 0,05 МэВ; декодированное облако совпадает с |ψ|² независимого пути в пределах половины 8-битного шага;
боттомоний меньше чармония, а ⟨r⟩ растёт: 1S < 1P < 2S; период суперпозиции равен 2πħ/ΔE, и она проходит проверки
периода, диполя и непрерывности; |m| > L подгоняется к ближайшему допустимому m с сообщением (UX-params P10), второе
состояние по умолчанию, равное первому, заменяется на 1S, равные состояния, выбранные вручную, и неортогональные
состояния отклоняются с причиной; высшие состояния (3D обеих систем) строятся и проходят; 1P_z, заданное на ходу в
идущем мире 1S, приготавливается в том же мире, его облако бит в бит как у мира, построенного с 1P_z, его проверки
проходят, а пара кварков как изменение на ходу отклоняется (ревью UX-ui U12).
